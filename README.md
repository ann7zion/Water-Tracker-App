# AquaTrack — Water Tracker

A simple, client-side water intake tracker. Log glasses of water throughout the day, watch your progress toward a daily goal, and review your last 7 days.

## Features

- Circular progress ring showing today's intake vs. your daily goal
- One-tap quick-add buttons plus a custom amount field
- Editable today's log (remove mistaken entries)
- 7-day history bar chart
- Switch between milliliters and fluid ounces
- Configurable daily goal
- All data persisted locally in the browser (`localStorage`) — no backend or account required

## Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL in your browser.

## Build

```bash
npm run build
```

## Tech stack

- React + TypeScript
- Vite
- Tailwind CSS
